# /stop 리소스팩

마인크래프트 26.3 영화 서버 /stop 의 리소스팩입니다. 서버가 접속한 사람에게 이 저장소의 릴리스 주소를 보내 자동으로 받게 합니다.
직접 받을 필요는 없습니다.

- 글꼴: Gowun Batang, Gowun Dodum, Nanum Pen Script, Poiret One (SIL Open Font License 1.1). 라이선스 전문은 팩 안 `assets/film/font/licenses/` 에 있습니다.
- 대사 음성: Microsoft Edge 신경망 음성(edge-tts)으로 생성
- 음악, 효과음, 텍스처, 셰이더: 코드로 생성
